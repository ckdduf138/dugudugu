# Third-party 3D assets

Third-party sources are accepted only with an explicit web-safe license,
preserved provenance, deterministic Blender cleanup, and runtime QA.

## `images/games/fortune-paper-texture-cc0.webp`

The fortune result strip uses a resized delivery derivative of **White Paper
Texture** by Petr Kratochvil, released under CC0/Public Domain. The photograph
provides restrained real paper fibers; CSS supplies the nearly straight
machine-cut silhouette, and DOM supplies all readable text and icons.

- Creator and source: Petr Kratochvil —
  https://www.publicdomainpictures.net/en/view-image.php?image=26025&picture=white-paper-texture
- License: CC0 / Public Domain
- Preserved source:
  `scripts/assets/fortune-ui/source-white-paper-texture-cc0.jpg`
- Deterministic delivery build:
  `scripts/blender/build_fortune_paper_texture.py`
- Downloaded and verified: 2026-08-03

The fortune tap guide uses the small `Hand` vector already supplied by the
project's Lucide React dependency (ISC license); no large pointer or separate
hand bitmap ships.

## `draw/gacha-machine.glb`

Original Dugudugu machine, capsule product system, materials, and cutscene-ready
node hierarchy. The deterministic source is `scripts/blender/build_gacha.py`;
no downloaded mesh or texture is embedded in the GLB.

## `ladder/ladder-mascot.glb`

Original Dugudugu ladder mascot with authored `Idle` and `Travel` clips. The
deterministic source is `scripts/blender/build_ladder_mascot.py`; no downloaded
mesh or texture is embedded in the GLB.

## `fortune/fortune-cookie.glb`

The shipped fortune-cookie GLB uses original Dugudugu source renders generated
from text prompts on 2026-07-29. No third-party image or model is embedded.
Blender removes the neutral source background, cleans and resizes the fixed
view, splits the opened cookie into independent left/right fracture parts, and
packs the 0.9-second `CrackReveal` animation. Provenance and unprocessed sources
are preserved in `scripts/assets/fortune-cookie-renders/`.

## Race production GLBs

`race/animals/animals-free.glb` is a final-product delivery built from
**Animals Free** by ITHappy Studios. It contains seven selectively exported,
normalized racers and their original Run animation clips in one shared-texture
GLB. The downloaded `.blend` is not redistributed by this repository.

- Creator and source: ITHappy Studios — https://ithappystudios.com/free/animals-free/
- License terms: https://ithappystudios.com/type-of-licenses/
- Re-supplied by the project owner and locally verified: 2026-08-02
- Local source SHA-256: `6979b2c0647c7e2bd157232c550199cc864d8978a044d2edba9395689aedadee`
- Production build: `scripts/blender/build_ithappy_race_animals.py`
- Delivery-GLB portrait build: `scripts/blender/render_race_delivery_icons.py`
- Lobby-card render: `scripts/blender/render_ithappy_race_card.py`
- Runtime cast: tiger, horse, deer, dog, cat, penguin, chicken

The ITHappy license permits commercial and personal final products while
prohibiting redistribution of source assets or derivative asset packs. Keep
the source `.blend` outside the repository and ship only the integrated game.

The earlier `race/horse.glb` and `race/zodiac/*.glb` remain original Dugudugu
models generated by `scripts/blender/build_zodiac_animals.py`; they are no
longer loaded by the live race.

## Archived race reference sources (not shipped)

The repository preserves two earlier reference/donor sets for provenance and
comparison. They are not embedded in the current production race GLBs.

### Cartoon Horse with animations

**Cartoon Horse with animations** by Jungle Jim is licensed under CC BY 4.0.

- Creator: Jungle Jim — https://sketchfab.com/jungle_jim
- Original model: https://sketchfab.com/3d-models/cartoon-horse-with-animations-1210663c398745cb9898e7d66fa51500
- License: Creative Commons Attribution 4.0 International —
  https://creativecommons.org/licenses/by/4.0/
- Downloaded and supplied by the project owner: 2026-07-19
- Preserved, unmodified source: `scripts/assets/cartoon-horse/source.zip`
- Local license/readme: `scripts/assets/cartoon-horse/LICENSE.txt` and
  `scripts/assets/cartoon-horse/README.md`
- Archived deterministic comparison build: `scripts/blender/build_cartoon_horse.py`

The archived comparison build converts the texture into a compact tintable
atlas and authors test `Idle` / `Run` actions. The free source archive does not
contain the creator's separately sold run, jump, or idle clips; those paid
animations are not used or reconstructed.
