# Quaternius horse source

`Horse.blend` is the unmodified horse from Quaternius' **Ultimate Animated
Animal Pack**, downloaded from the official distribution. The pack is CC0.

- Creator: Quaternius
- Official page: https://quaternius.com/packs/ultimateanimatedanimals.html
- License: CC0 1.0; see `LICENSE.txt`
- Preserved source size: approximately 2.7 MB
- Production derivative: `public/models/race/horse.glb`
- Deterministic remaster/export: `scripts/blender/build_horse.py`

The production GLB is a derivative: Dugudugu changes the silhouette, surface,
materials and accessory design, retains only `Idle` and `Gallop` motion data,
closes the gallop loop, renames it to `Run`, and exports a web-budgeted asset.
Do not overwrite this source file with the derivative blend.
