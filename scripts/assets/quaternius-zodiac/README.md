# Quaternius zodiac donor sources

These untouched `.blend` files are preserved inputs for
`scripts/blender/build_zodiac_animals.py`. They are not served by the site.

All source packs are by **Quaternius** and were published under **CC0**:

- `Bull.blend`, `ShibaInu.blend` — Ultimate Animated Animal Pack
  https://quaternius.com/packs/ultimateanimatedanimals.html
- `Rat.blend`, `Snake.blend` — Easy Enemy Pack
  https://quaternius.com/packs/easyenemy.html
- `Pig.blend`, `Sheep.blend` — Farm Animal Pack
  https://quaternius.com/packs/farmanimal.html
- `Chicken.blend`, `Panda.blend`, `YellowDragon.blend` — Cute Animated
  Monsters Pack
  https://quaternius.com/packs/cuteanimatedmonsters.html

Derivative mapping used in the race:

- Rat → rat and rabbit variants
- Bull → ox
- Shiba Inu → dog and tiger variants
- Yellow Dragon → dragon
- Snake → snake
- Sheep → sheep
- Panda → monkey variant
- Chicken → rooster variant
- Pig → pig

The horse remains the separately attributed Jungle Jim CC BY 4.0 asset in
`scripts/assets/cartoon-horse/`.
