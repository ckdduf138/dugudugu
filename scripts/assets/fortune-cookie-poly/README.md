# Fortune Cookie source

`fortune-cookie-source.glb` is a preserved low-poly blockout that was evaluated
during fortune-cookie development. It is no longer used by the production
build or shipped GLB.

- Title: **Fortune cookie**
- Creator: **Poly by Google**
- Source: https://poly.pizza/m/8diHwxl9PEK
- Original upload: 2017-10-22
- License: Creative Commons Attribution 3.0 Unported
- License URL: https://creativecommons.org/licenses/by/3.0/
- Downloaded from the source page's public model URL: 2026-07-29

The source remains in the repository only to preserve its CC-BY attribution and
the rejected blockout's audit trail. The production build uses the original
Dugudugu renders documented in `scripts/assets/fortune-cookie-renders/`.
